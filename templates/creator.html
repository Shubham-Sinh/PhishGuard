01 / ABOUT

Building with a security-first mindset.

PhishGuard was created as a cybersecurity project focused on helping users understand the risks hidden inside URLs. The project combines machine learning with URL-based security signals to classify suspicious links.

The goal is simple: make phishing detection easier to understand while exploring practical applications of machine learning and web development.
